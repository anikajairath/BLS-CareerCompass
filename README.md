# BLS CareerCompass 📊

An end-to-end labor-market data analysis and career recommendation project built using **real, publicly available data from the U.S. Bureau of Labor Statistics (BLS)**.

The project combines data cleaning, exploratory analysis, SQL, feature engineering, machine learning, semantic retrieval, and generative AI to build **CareerCompass** — an interactive system that helps users explore occupations and compare potential career locations across the United States.

## 🎯 What is CareerCompass?

CareerCompass allows users to ask natural-language questions such as:

> "What does a data scientist do, and which states are best for a data scientist career?"

The system combines occupational information with BLS labor-market data to provide:

- Occupational information
- State recommendations
- Metropolitan-area recommendations
- Median wages
- Employment levels
- Location quotients
- Projected growth
- Annual openings
- CareerCompass scores

---

## 🗂️ Data Sources

The project uses six core BLS datasets:

- **National OEWS**
- **State OEWS**
- **Metropolitan Area OEWS**
- **Balance of State (BOS) OEWS**
- **Employment Projections, 2025–2035**
- **Occupational Openings**

BLS Occupational Outlook Handbook (OOH) information is also used to provide occupational descriptions and career context.

The occupation/SOC code is used to connect current labor-market information with employment projections and occupational information.

## 🧮 CareerCompass Score

For a selected occupation, locations are compared using three labor-market indicators:
- Median annual wage
- Employment
- Location quotient
Each is converted to a percentile within the occupation.

CareerCompass Score = (Wage Percentile + Employment Percentile + Location Quotient Percentile) / 3

The score is used to rank states and metropolitan areas for a particular occupation.
Projected growth and annual openings are provided as additional occupational context.

## 🤖 RAG + Generative AI

CareerCompass uses Retrieval-Augmented Generation to retrieve occupational information from a BLS OOH-based knowledge base.
Current knowledge base:
- 343 occupational records
- 684 searchable chunks
Google Gemini is used as the explanation layer.
Importantly, Gemini does not calculate the CareerCompass score or independently calculate labor-market metrics. Numerical recommendations are generated by the structured CareerCompass engine and then supplied to Gemini for explanation.

## ⚠️ Limitations

- CareerCompass is a comparative labor-market score, not a prediction of individual career success.
- The current score uses equal weighting for wage, employment, and location quotient.
- Projected growth and openings are national occupational projections rather than location-specific forecasts.
- Some BLS wage values are subject to publication thresholds.
- Semantic retrieval may occasionally return a related occupation.
- The machine-learning component is exploratory rather than production predictive modeling.
